# RoomMatch typography

RoomMatch uses Fraunces for display headings and Manrope for interface text. Both are loaded from Google's font CSS service and have system fallbacks for offline use.

- Fraunces: https://fonts.google.com/specimen/Fraunces
- Manrope: https://fonts.google.com/specimen/Manrope
- Both are distributed under the SIL Open Font License (OFL); consult the Google Fonts specimen pages for the release metadata.

Binary font files are not self-hosted in this delivery because the execution environment could not retrieve official font binaries. The UI remains functional with its configured fallbacks when the font service is unavailable.
